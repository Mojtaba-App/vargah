# ADR-003: امنیت و احراز هویت پنل مدیریت

**وضعیت:** پذیرفته‌شده  
**تاریخ:** ۱۴۰۵/۰۶

## زمینه

پنل مدیریت دسترسی به محتوا، مالی و تنظیمات حساس دارد. نیاز به استانداردهای OWASP و احراز هویت قوی.

## تصمیم

- بسته `@vargah/security` برای منطق مشترک
- **bcrypt** برای hash رمز
- **JWT** (Auth.js) با عمر کوتاه (۱۵ دقیقه) + **refresh token** چرخشی
- **TOTP 2FA** اجباری برای نقش‌های حساس (مدیر کل، سردبیر)
- **Rate limiting** روی login و فرم‌های عمومی
- **CSRF** برای Server Actions
- **DOMPurify** برای sanitize محتوای HTML
- **Zod** برای اعتبارسنجی ورودی
- هدرهای امنیتی HTTP در web، admin و cms

## پیامدها

### مزایا

- لایه امنیت متمرکز و قابل تست
- چک‌لیست امنیت + ZAP در CI

### معایب

- سردبیر باید 2FA راه‌اندازی کند
- پیچیدگی بیشتر در flow ورود
