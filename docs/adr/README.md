# ADR — Architecture Decision Records

تصمیمات معماری مهم پروژه وارگه در این پوشه ثبت می‌شوند.

## قالب

هر ADR شامل:

1. **وضعیت** — پیشنهادی / پذیرفته‌شده / منسوخ
2. **زمینه** — مشکل یا نیاز
3. **تصمیم** — چه انتخابی شد
4. **پیامدها** — مزایا، معایب، کارهای بعدی
