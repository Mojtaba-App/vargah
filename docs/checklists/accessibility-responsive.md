# چک‌لیست دستی: دسترسی‌پذیری و واکنش‌گرایی

این چک‌لیست را **قبل از هر انتشار** روی حداقل سه اندازه صفحه اجرا کنید.

## اندازه‌های تست

| نام    | عرض    | دستگاه نمونه      |
| ------ | ------ | ----------------- |
| موبایل | ۳۷۵px  | iPhone SE / Pixel |
| تبلت   | ۷۶۸px  | iPad              |
| دسکتاپ | ۱۲۸۰px | لپ‌تاپ            |

در Chrome DevTools: `F12` → Toggle device toolbar → اندازه را تنظیم کنید.

## صفحات الزامی

- [ ] یک مقاله منتشرشده
- [ ] اشتراک `/subscription`
- [ ] تماس `/contact`

- [ ] داشبورد `/`
- [ ] لیست مقالات `/content/articles`
- [ ] فرم مقاله جدید `/content/articles/new`
- [ ] کتابخانه رسانه — آپلود و حذف

## دسترسی‌پذیری (Accessibility)

### کیبورد

- [ ] با `Tab` می‌توان به همه لینک‌ها و دکمه‌ها رسید
- [ ] ترتیب Tab منطقی است (بالا به پایین، راست به چپ در RTL)
- [ ] `Enter` / `Space` فرم‌ها و دکمه‌ها را فعال می‌کند
- [ ] منوی موبایل با کیبورد قابل استفاده است
- [ ] هیچ عنصری در حلقه فوکوس گیر نمی‌کند (focus trap ناخواسته)

### بصری و خوانایی

- [ ] حلقه فوکوس (outline) روی عناصر تعاملی دیده می‌شود
- [ ] کنتراست متن و پس‌زمینه کافی است (حداقل ۴.۵:۱ برای متن معمولی)
- [ ] اندازه فونت در موبایل خوانا است (حداقل ۱۶px برای متن بدنه)
- [ ] تصاویر مهم `alt` دارند
- [ ] عناوین صفحه (`<h1>`) یکتا و معنادار هستند

### فرم‌ها و بازخورد

- [ ] هر فیلد `label` مرتبط دارد
- [ ] خطاهای اعتبارسنجی با `role="alert"` نمایش داده می‌شوند
- [ ] پیام موفقیت با `role="status"` نمایش داده می‌شود
- [ ] فیلدهای اجباری مشخص شده‌اند

### جداول پنل

- [ ] هدرهای قابل مرتب‌سازی با کیبورد (`Enter`/`Space`) فعال می‌شوند
- [ ] ستون مرتب‌شده `aria-sort` دارد
- [ ] جدول `caption` یا نام دسترس‌پذیر دارد
- [ ] وضعیت تعداد ردیف‌ها با `aria-live` اعلام می‌شود

### RTL / LTR و چندزبانه

- [ ] `dir="rtl"` برای `fa` و `dir="ltr"` برای `en` روی `<html>` تنظیم است
- [ ] اعداد و تاریخ در جای درست نمایش داده می‌شوند
- [ ] فیلدهای ایمیل/URL جهت `ltr` دارند

## واکنش‌گرایی (Responsive)

### موبایل (۳۷۵px)

- [ ] هدر جمع‌شده / منوی همبرگری کار می‌کند
- [ ] اسکرول افقی ناخواسته وجود ندارد
- [ ] دکمه‌ها قابل لمس هستند (حداقل ۴۴×۴۴px)
- [ ] جداول در صورت نیاز اسکرول افقی دارند
- [ ] فرم خبرنامه در یک ستون چیده شده

### تبلت (۷۶۸px)

- [ ] گرید مقالات / پلن‌ها ۲ ستونه است
- [ ] سایدبار پنل مدیریت قابل استفاده است
- [ ] فاصله‌ها متعادل است

### دسکتاپ (۱۲۸۰px)

- [ ] محتوا بیش از حد کش نمی‌آید (`max-width` رعایت شده)
- [ ] سایدبار پنل ثابت و خوانا است
- [ ] نمودارهای داشبورد کامل نمایش داده می‌شوند
